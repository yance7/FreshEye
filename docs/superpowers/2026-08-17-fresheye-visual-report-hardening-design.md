# FreshEye 视觉、内容与报告体验升级设计

日期：2026-08-17

## 目标

在不改变后端预测接口、模型输入输出契约和现有 Vue 3 路由架构的前提下，完成 FreshEye 前端的视觉精修、双语内容校正、旧版信息恢复、报告单页化、热力图尺寸约束、移动端适配和高频交互稳健性升级。

旧版 `frontend/about.html`、`frontend/assets/locale-zh.js`、`frontend/assets/locale-en.js` 与 `frontend/assets/pdf-report.js` 是内容和报告结构的事实基线；当前 `frontend-vue` 负责运行实现。所有项目数据、模型指标、免责声明和文献条目以仓库已有事实或可核验出版信息为准，不新增未经验证的模型能力。

## 设计方向

保留“深海观测仪器”视觉身份：深海蓝背景、青绿色强调色、玻璃卡片和细线数据感不变，但降低圆角和阴影的随意感，建立统一的间距、层级和交互节奏。页面阅读顺序统一为：标题/结论 → 解释/证据 → 操作/建议 → 边界说明。

采用 Vue 原生组合式逻辑和 CSS，不引入新的运行时依赖。需要复用的视觉规则放入全局设计令牌或页面已有样式；内容继续由 `src/i18n/zh.ts` 与 `src/i18n/en.ts` 驱动。

## 视觉系统

### 令牌

- 间距使用 4px 基础阶梯，正文卡片优先使用 12/16/20px 内边距，区块间距使用 28/40px，避免相邻卡片粘连或标题与内容脱节。
- 小型控件使用 8px 圆角，普通卡片使用 14px，重点卡片使用 18px；仅使用 999px 胶囊形状表示状态、标签或语言切换，不把所有容器都做成胶囊。
- 统一边框透明度、悬停边框和焦点环；阴影只用于主结果卡、弹层和导航，不在每个小卡片上叠加重阴影。
- 动画统一使用快速 160ms、标准 240ms、展开 280ms 三档；所有 transform/opacity/filter 动画都服从 `prefers-reduced-motion`。

### 导航与任务栏

- 桌面端导航保持品牌、页面链接、语言切换同一基线；语言组件为清晰的 `中 / EN` 分段控件，活动段有实心青色背景，点击区域不小于 44px。
- 移动端导航遮罩保留焦点管理和 Escape 关闭，菜单链接与语言控件拥有稳定的垂直节奏。
- 结果区任务栏把服务状态、报告导出和上下文动作归为一组，允许窄屏换行；导出按钮保持主要操作优先级，服务状态不抢占标题空间。
- Tab 采用可横向滚动的分段控件，活动态、键盘焦点和触控反馈一致，切换不强制滚动页面。

## 页面内容与卡片

### 指南页

“正确示例”和“错误示例”使用同一套双列 `photo-check-card` 组件：顶部状态标签、简短结论、逐条检查项。每条检查项独立成为带编号/标记的行，不再把加粗标题和正文拼成视觉上错位的长列表。移动端改为单列，正确与错误卡片保持相同内边距、行高和标题基线。

FAQ 改为真正的 `<button>` 标题和可动画内容区，保留问答完整文本；折叠内容不使用固定 `max-height`，避免英文长文本或高频点击时裁切。

### 关于页

“面向三类使用者”和“为什么选择鱼眼作为入口？”统一为信息卡片网格，使用图标、标题、正文三层结构，并给每张卡设置 `min-height` 让同一行卡片视觉对齐。正文用准确、克制的辅助评估表述，明确鱼眼是视觉入口而不是完整食品安全结论。

About 页恢复旧 HTML 中缺失的完整信息：项目事实卡、技术架构、痛点与解法、鱼眼入口理由、三类使用者、模型表现、Model Card、FishFreshNetV1 结构、CBAM 与 Grad-CAM 解释、FishFreshNetV2 结构、ECA 与 Light CRA、V1/V2 对比、推理流水线、创作历程、社会价值、迭代规划和参考文献。长段技术说明通过“摘要卡 + 详情折叠卡 + 对比表”排版，保持信息完整但避免一整面连续文字。

参考文献以完整作者/年份/题名/出版物/页码或 DOI 形式呈现，并把 FFE 数据集单独标出。优先链接 DOI、出版社、CVF、PMLR、arXiv 或 Mendeley Data 页面；不把未核验的指标写成泛化准确率。

## 首页结果区

- 概览首屏保留等级、置信度、操作建议和概率分布，建议文案明确“视觉参考”和需要结合鱼鳃、气味、肉质及储存条件的边界。
- 详细报告卡片显示“标题 → 结论段 → 支撑条目”，标题不重复结论内容；建议卡片显示“类别标题 → 建议条目”，不再把第一条建议同时渲染为描述和列表第一项。
- 建议分为储存、食用、处理、安全、最佳实践五类；安全项使用警示色但不制造模型无法证明的食品安全结论。

## 折叠交互稳健性

所有 Vue 折叠组件统一使用真实按钮、`aria-expanded`、稳定的 `aria-controls` 和唯一 ID。内容区使用 CSS Grid 的 `0fr`/`1fr` 动画，内部区域设置 `min-height: 0` 与 overflow 控制，不使用任意固定高度。状态只由单一布尔值源驱动；连续点击始终以最后一次用户意图为准，不启动额外定时器、不注册重复事件、不读写布局高度。

路由切换、语言切换和组件卸载时清理观察器、指针监听和定时器，避免旧页面监听器继续触发。交互测试覆盖鼠标、触摸、键盘 Enter/Space，以及连续快速展开/收起。

## Grad-CAM 展示

比较容器在桌面端使用 `width: min(100%, 640px)`，图片区域保持原始比例，最大高度随视口限制；移动端宽度为容器可用宽度，保持触控滑块和标签可见。图片不再让其自然尺寸撑开整个结果页面。比较滑块继续使用 pointer events 和 `touch-action: none`，结束/取消/离开时释放拖拽状态。

## PDF 报告

报告窗口继续由 `buildReportHtml()` 生成，不依赖外部样式表，避免 Blob/CSP 和离线部署问题。打印版使用旧 HTML 报告的单页 A4 结构：

1. 页面顶部品牌、报告标题、模型/耗时/时间元信息；
2. 左侧原图与热力图并排，右侧结论等级与置信度；
3. 三分类概率条；
4. 视觉特征、趋势和标准对照的紧凑证据区；
5. 双列建议卡和安全提示；
6. 使用边界、验证范围和页脚。

屏幕预览保留工具栏和响应式阅读体验；打印时隐藏工具栏，固定 A4 页面宽度、边距和颜色打印规则，所有主要区块 `break-inside: avoid`。报告内容按页高预算压缩字体、间距和图片高度，不依赖“内容超出后再溢出”的假单页。生成 HTML 下载与打印按钮都保留，文件名随中英文 locale 变化。

## 响应式与动画

- 桌面端重点保证 1024px、1280px、1440px 的内容宽度和热力图比例；平板在双列与单列之间平滑切换。
- 移动端重点验证 320px、360px、390px 和 430px：导航、语言切换、上传/相机、结果 Tab、滑块、折叠、历史记录和 PDF 操作均可用；按钮触控区域不小于 44px，长英文不会撑破布局。
- 入场 reveal 只观察未完成节点，组件卸载后断开观察器；动态背景和装饰动画不影响交互与低性能设备。

## 验收证据

- `npm test`：契约测试覆盖旧版信息恢复、建议不重复、折叠按钮语义、热力图尺寸约束、单页 A4 标记和双语关键文案。
- `npm run typecheck` 与 `npm run build`：类型检查和生产构建通过。
- 浏览器验收：桌面/移动截图对比；无控制台错误；快速点击折叠最终状态稳定；热力图边界在视口内；中英文切换后页面与报告文本同步。
- PDF 验收：使用浏览器打印为 PDF 后通过 PDF 页数检查确认恰好 1 页，并渲染检查页面视觉布局。
- Git 验收：工作区只包含本次改造，提交直接推送远端 `main`，不创建 PR。

## 不改变的边界

- 不改动 `/predict_with_gradcam` 接口、模型文件、预测标签含义和后端推理逻辑。
- 不把视觉概率改写为食品安全概率，不增加保质期保证、法定检测或医学/监管结论。
- 不删除旧版事实信息；如果旧版条目与当前代码事实冲突，优先保留可核验仓库事实并在文案中标明验证范围。
