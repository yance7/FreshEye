痛点 vs 解法

! 当前痛点
  • 肉眼判别依赖个人经验，新手难以掌握
  • 化学检测成本高、周期长，且破坏样品
  • 现有工具只给结论，不告诉"为什么"与"怎么办"
  • 便携式仪器单价 5000-20000 元，基层摊位难以普及，且需定期校准维护
  • 传统感官评估存在评估者间变异性，不同检查员对同一样本结论可能不一致
✓ FreshEye 解法
  • 鱼眼照片一键上传，零成本非破坏式检测
  • FishFreshNetV1（EfficientNet-B0 + CBAM）三分类，准确率 99%+；V2（EfficientNet-B0 + ECA + Light CRA）提升至 99.29%
  • Grad-CAM 热力图解释"为什么"，结构化报告给出"怎么办"
  • 置信度驱动自适应分支，低置信度主动提示重拍

🧠 EfficientNet-B0 骨干网络

鱼眼新鲜度评估是一个细粒度视觉分类任务，需要高精度且计算高效的神经网络来适配移动端部署。FishFreshNetV1 选用 EfficientNet-B0 作为基础架构，核心优势如下：

  • 复合缩放方法（Compound Scaling）[6]：EfficientNet 通过统一的复合系数 φ 同时缩放网络深度（depth）、宽度（width）和输入分辨率（resolution），三者协同优化而非单一维度扩展，在保持高精度的同时显著减少参数量。
  • MBConv 模块（Mobile Inverted Bottleneck Convolution）：作为 EfficientNet-B0 的基本构建单元，MBConv 采用深度可分离卷积 + 反残差结构（先升维→深度卷积→降维），在大幅降低计算量的同时保持高特征提取能力。
  • 自定义分类头：移除 EfficientNet-B0 原始分类头，替换为自适应平均池化层（Adaptive Average Pooling）→ Dropout 层 → 线性全连接层，有效缓解训练过拟合并映射到三个新鲜度类别（高度新鲜 / 新鲜 / 不新鲜）。

🎯 CBAM 注意力机制

在实际检测场景中，鱼眼图像常包含大量无关信息（泡沫箱、光照变化、鱼鳞等）。为使网络聚焦于关键鱼眼区域，FishFreshNetV1 在 EfficientNet-B0 最后一个特征提取层之后（输入通道数 1280）集成了 CBAM（Convolutional Block Attention Module）[7]。CBAM 是一个轻量级注意力模块，沿通道和空间两个维度依次推送注意力图：

通道注意力子模块

对特征图同时执行最大池化和平均池化，将两个池化结果输入共享的多层感知机（MLP）。MLP 通过先降维再升维的结构学习通道间依赖关系，输出通道注意力权重。

→ 帮助模型推断哪些特征通道真正具有判别力（如角膜浑浊度相关的特征通道）

↓ 特征图 × 通道权重
空间注意力子模块

沿通道轴执行池化操作（最大池化 + 平均池化），生成 2 通道的聚合特征，再通过卷积层生成空间注意力图。

→ 引导网络聚焦瞳孔和角膜区域，抑制背景环境（砧板、纸张、泡沫箱）的干扰

↓ 特征图 × 空间权重
自适应特征精炼

两张注意力图分别与输入特征图相乘，实现通道和空间维度的自适应特征精炼，在模型体积与识别精度之间取得平衡。

🔥 Grad-CAM 可解释性

为克服深度神经网络的"黑箱"问题，FishFreshNetV1 引入 Grad-CAM（Gradient-weighted Class Activation Mapping）[8] 可视化技术：

  • 利用目标类别梯度流入 EfficientNet-B0 最后一个卷积层，生成粗粒度定位图
  • 对梯度执行全局平均池化，计算每个特征通道的重要性权重
  • 生成热力图，高亮对模型预测影响最大的图像空间区域

实验表明：在正确分类的案例中，红色高激活区域精准聚焦于瞳孔和角膜；在错误分类的案例中，高激活区域偏移至眼周明亮鱼鳞或镜面反射光斑——这证实模型确实依据生物学特征做出判断，而非依赖背景捷径。

FishFreshNetV2 模型架构

FishFreshNetV2 是在 V1 基础上完成的学术升级版本。V2 的核心目标是在保持轻量化的前提下进一步提升精度与可解释性，关键改动有两点：用 ECA 替代 CBAM 作为通道注意力，并新增 Light CRA（Light Circular Region Attention）鱼眼专用区域注意力。模型仅 4.095M 参数、0.414G FLOPs，在 MFED 数据集上达到 99.29% 准确率。

⚡ ECA 通道注意力（替代 CBAM）

V1 使用的 CBAM 同时引入通道注意力子模块（共享 MLP）和空间注意力子模块（卷积层），会带来额外的参数开销。V2 改用 ECA-Net（Efficient Channel Attention）[9]提出的高效通道注意力，核心思想是：用一维卷积替代全连接 MLP，让相邻通道直接交互，避免降维带来的信息损失。

零额外参数：ECA 仅一个一维卷积核（k 个权重），不引入任何通道降维参数。核大小 k 由通道数 C 自适应决定：k = 2 × ⌊log₂(C) / 2 + 0.5⌋ - 1，最小取 3。
局部跨通道交互：与 CBAM 的全局 MLP 全连接不同，ECA 通过一维卷积实现局部邻域的通道交互，更高效地捕获通道间依赖关系。
与 Light CRA 分工互补：ECA 负责轻量通道调制，Light CRA 负责区域注意力，两者分工互补，无需 CBAM 的空间注意力子模块。

🎯 Light CRA 环形区域注意力

这是 V2 引入的原创模块，利用鱼眼近似圆形的几何先验，将特征图划分为 N=3 个同心环（瞳孔 / 角膜 / 眼眶）并分别施加注意力。原始 CRA 参数高达 13.846M，Light CRA 通过"掩码分区 + 共享深度卷积"压缩到仅 0.083M，却带来 +0.37% 准确率提升（98.88% → 99.25%）。

三环语义结构：N=3 对应鱼眼的三段语义结构——内环（瞳孔）、中环（角膜）、外环（眼眶），每个环独立生成注意力权重，使模型聚焦于不同半径区域的新鲜度特征。
轻量化设计：通过预生成的环形掩码分区特征图，共享一个深度卷积核处理所有环，将参数量从原始 CRA 的 13.846M 压缩至 0.083M（压缩率 99.4%）。
环形数量消融验证：消融实验证实 N=3 最优——N=1 退化 为全局注意力（无区域先验），N=5 划分过细导致语义碎片化，N=3 与鱼眼三段结构完美对应。

创作历程

💡

灵感诞生

陪家人去菜市场买鱼，摊主信誓旦旦"绝对新鲜"，回家切开却已发臭。发现鱼眼是反映新鲜度最关键的视觉信号[10]，但人眼无法分辨细微差距——如果 AI 能看懂鱼眼呢？

🔬

独立研究

独立设计 EfficientNet-B0 + CBAM 架构（FishFreshNetV1），构建 MFED 数据集（4800 张 / 4 环境 / GB 2733-2015 国标[11]），达成 99%+ 准确率。数据集开源至 Mendeley Data。

⚙️

后端开发

FastAPI + PyTorch 模型推理服务，部署至 Hugging Face Spaces。FishFreshNet V1/V2 双模型支持，置信度自适应前端提示机制，Grad-CAM 可解释性热力图。

🎨

前端开发（初赛）

TRAE Work 5 次对话从零到交付。项目奠基 → 视觉升级 → API 集成 → 结果深化 → 打磨交付。单文件 HTML 149KB，深海动态主题 + 4-Tab 分析报告 + 离线演示模式。

🚀

复赛迭代

多页面重构 → 移动端深度适配 + PWA → 置信度自适应前端机制 → 最终交付打磨。从"能用的 Demo"进化为"好用的产品"。
